# Mori 1.0.0

First stable release of Mori.

Mori is a private, offline media and file browser for inspecting local folders and external drives, including ones you don't trust. It browses them like a Finder-style gallery, and it previews photos, videos, PDFs and archives without handing the originals to other apps. It finds duplicates, reads metadata and checks file integrity. Everything runs on your computer: there is no account, no cloud, no telemetry and no network functionality.

## Highlights

**Browse and preview**
- Fast local browsing of folders and external drives in Gallery, Grid and List views, with search, filters, subfolder views, a command palette and keyboard navigation.
- **Safe previews:** images and HEIC are decoded in a sandboxed worker and shown as re-encoded copies.
  - PDFs are rendered as bitmaps with nothing interactive executed.
  - Archives are listed, never extracted, with traversal and bomb checks.
  - Video plays with a filmstrip, audio with a waveform.

**Inspect unknown drives**
- **Private Inspection:** one step to browse a drive read-only, in a temporary session, with automatic decoding off. *End Session* clears everything Mori held about it.
- **Safe Drive Mode:** a drive Mori has never seen is indexed from filesystem metadata only, and nothing is decoded until you ask.
- **Temporary Sessions:** browse without Mori keeping an index, thumbnails, history or records afterwards.
- **Real file type detection** and **risk indicators:** disguised executables, double extensions, hidden direction characters, truncated or extreme media.

**Protect your files and data**
- **Private folders:** a visibility boundary inside Mori. Not encryption; your files are unchanged.
- **Read-only Mode** and **protected folders** (Never Modify), enforced in the backend.

**Analyze**
- **Metadata inspection** and a **Sensitive Metadata scanner** for location, device and personal fields, an offline **Places** map, and sanitized copies.
- **Duplicate detection** by content hash, and **Similar Media** by perceptual comparison.
  - **Difference View** and side-by-side comparison.
  - A suggested **Best Copy** that explains its reasons.
- **SHA-256 integrity:** checksums, Compare Integrity for two files, and folder integrity snapshots that report Unchanged / Changed / Missing / New.
- **Storage analysis** with a treemap, **Media Health** for broken and unsupported media, and Empty Folders.

**Organize and manage**
- **Tags and favorites**, kept in Mori's own data.
- **Careful file operations:** Move to Trash with Undo, and Delete Permanently behind an Operation Preview.

**Diagnostics**
- A self-test on synthetic files shows which media, security, privacy, network and ephemeral protections are verified on your installation, with no hard-coded check marks.

## Privacy & security

- **Privacy.** Your files and what Mori learns about them stay on your computer. **Privacy & Local Data** lists everything Mori stores, with sizes, and lets you clear it selectively or reset Mori. Mori never deletes or changes your files when doing so.
- **Security.** Every file is treated as untrusted input. Decoding happens in worker processes that receive bytes, never paths. On macOS the system sandbox denies those workers file access, network access and new processes. Links are never followed.
- **Offline.** Core features work without an internet connection. The interface refuses every remote origin, and the decoder workers are denied network access by the OS sandbox. The main process has no network code, but it is not sandboxed from the network.
- **Ephemeral inspection.** Temporary sessions and Private Inspection keep their data in memory and clear it when the session ends. An automated test verifies that a session leaves nothing in Mori's own data.

Mori is **not antivirus software**: it reports observations, never verdicts like "safe". No sandbox is an absolute guarantee. Mori minimises its own traces but cannot remove those created by the operating system or other software. See [SECURITY.md](https://github.com/emagrina/mori/blob/main/SECURITY.md) and the [privacy inventory](https://github.com/emagrina/mori/blob/main/docs/privacy.md).

| File | Platform | Status |

| `Mori_1.0.0_macOS_x64.dmg` | macOS, Intel | Built and tested on an Intel runner; launched under Rosetta, not on Intel hardware |

- **macOS** declares version 11 as its minimum; versions before 26 haven't been tested.
- **Windows and Linux** are earlier-stage builds:
  - **Weaker isolation:** decoder workers get resource limits and never receive file paths, but no OS sandbox denies them file access as on macOS.
  - **macOS-only features:** HEIC previews, PDF previews, new-drive detection and Undo for Trash.
  - **Untested by hand:** please report problems.

## Installation

Verify your download (optional): `shasum -a 256 -c SHA256SUMS.txt --ignore-missing` on macOS and Linux, or `Get-FileHash <file> -Algorithm SHA256` in PowerShell, compared with the line in `SHA256SUMS.txt`.

None of these builds is signed with a publisher certificate yet, so each system warns once. You never need to disable Gatekeeper, SmartScreen or any other protection.

**macOS**
1. Open the DMG and drag **Mori** into **Applications**, then open Mori.
2. macOS blocks the first launch with *"Apple could not verify “Mori” is free of malware…"*:
   - **macOS 15 and later:**
     1. Click **Done**.
     2. Open **System Settings → Privacy & Security**.
     3. Click **Open Anyway** next to the Mori message, and confirm.
   - **macOS 14 and earlier:** Control-click Mori → **Open** → **Open**.

**Windows**
1. Run `Mori_1.0.0_Windows_x64-setup.exe` (or the `.msi`).
2. Microsoft Defender SmartScreen shows *"Windows protected your PC"* with **Unknown publisher**. Click **More info → Run anyway**.
3. Mori needs Microsoft Edge WebView2, which Windows 11 includes. If it's missing, the installer downloads it from Microsoft. That download is the installer, not Mori.

**Linux**
- **AppImage:**
  1. `chmod +x Mori_1.0.0_Linux_x64.AppImage`, then run it.
  2. It needs FUSE 2: `sudo apt install libfuse2` on Ubuntu 22.04, or `libfuse2t64` on 24.04.
- **Debian/Ubuntu:** `sudo apt install ./Mori_1.0.0_Linux_x64.deb`.
- **Video and audio playback** use the system's GStreamer plugins (for example `gstreamer1.0-plugins-good` and `gstreamer1.0-libav`).

## Known limitations

- No build is signed with a publisher certificate or notarized (see Installation).
- Windows and Linux builds haven't been tested by hand yet, and have weaker decoder isolation than macOS.
- Video and audio are played by the system's media engine, which runs outside Mori's sandbox.
- HEIC and PDF previews, new-drive detection and Undo for Trash are macOS features.
- Similar Media results are estimates; review them before removing anything.
- Secure Overwrite is refused on APFS and SSDs, which includes a typical Mac. Mori never claims files are unrecoverable.
- Traces outside Mori's control remain possible: file-system journals, swap, snapshots, backups, crash reports, SSD behaviour, Spotlight, third-party software.
