# Mori 1.0.1

A patch release that makes Mori a more complete everyday file browser, plus video and tag fixes.

Mori remains a private, offline-first media and file browser: everything runs on your computer, with no account, no cloud, no telemetry and no network functionality. The full feature set is described in the [Mori 1.0.0 release notes](https://github.com/emagrina/mori/releases/tag/v1.0.0) and in [docs/features.md](https://github.com/emagrina/mori/blob/main/docs/features.md).

## Highlights

**File management**
- **Desktop-style selection** in every view, in search results and with *Include subfolders*.
  - A click selects, and a double-click or Return opens.
  - Cmd/Ctrl+Click, Shift+Click, Shift+arrows and ⌘A/Ctrl+A select several items; Esc clears.
  - A selection bar shows "N selected" with Move to…, Copy to…, Tags, Favorite and Move to Trash.
- **Move to… and Copy to…** (`M` / `⇧M`) for files and folders, one or many.
  - Mori shows what will happen first, including anything it refuses: Read-only Mode, protected folders, a folder into itself.
  - Name conflicts offer **Keep Both**, **Replace** (the existing file goes to the Trash first) or **Skip**. Nothing is overwritten in place.
  - A move to another drive copies, checks the copy, and only then sends the original to the Trash.
  - Partial failures are reported item by item. Undo moves items back (for moves to another drive, on macOS only, as it uses the Trash).
- **Drag and drop** onto folders in the grid, list and sidebar, with clear accept / refuse feedback. Dragging moves the whole selection through the same checks as Move to….
  - Sidebar folders expand when you hold over them.
  - Option/Alt copies.
- **Manage the file you're viewing**: the preview's `…` menu has Get Info, Favorites, Checksum, Rename, Move to…, Copy to… and Move to Trash. After a move or trash, the preview continues with the next file.

**Quick Cleanup**
- Go through a folder one file at a time from the keyboard: **Keep** (→ / K) or **Mark for Trash** (← / D), with Undo, Back, Skip and progress.
- **Nothing moves while you review.** Decisions are only staged. At the end you review the marked items, can restore any of them, and confirm once. They then go to the system Trash, never a permanent delete; on macOS, Undo brings them back.
- Held-down keys and bounced presses can't mark extra files, and protected files can't be marked.
- Unfinished cleanups can be resumed later. In Temporary Sessions and Private Inspection they are never saved, and while read-only the final step is unavailable.

**Favorites and tags**
- A clear **Favorite star** on each thumbnail: filled when set, an outline on hover, clickable without opening the file. List view has its own star, and the sidebar shows a Favorites count.
- **Rename Tag… / Delete Tag…** from a tag's right-click menu in the sidebar.
  - Renaming keeps every tagged item, and duplicate names are refused, never merged.
  - Deleting a tag removes only the tag: **no files are deleted or changed**.

**Video fixes**
- **Quick Cleanup no longer crops portrait videos.** Vertical clips (for example 720×1280) are now shown whole, with black bars at the sides, like in the normal viewer.
- **Filmstrip frames keep the video's real shape.** Portrait and rotated phone videos get narrow portrait frames instead of landscape crops.
- Video details report the displayed size of rotated phone videos.

## Safety and privacy

- Every new file operation (move, copy, drag and drop, Quick Cleanup's final step) goes through the same backend checks as before: Read-only Mode, protected folders (Never Modify) and Private Inspection are enforced there, not just in the interface. Links are moved or copied as links; what they point to is never touched.
- Quick Cleanup's resumable sessions save only opaque item ids and decisions, never names or paths. They are listed in **Privacy & Local Data**, and are never written in temporary sessions.
- Dragging carries no file paths outside Mori, and files dropped from other apps are ignored.

| `SHA256SUMS.txt` | | SHA-256 of every file above |

Installation is unchanged from 1.0.0. The builds aren't signed with a publisher certificate yet, so each system warns once; the [1.0.0 notes](https://github.com/emagrina/mori/releases/tag/v1.0.0) explain how to open Mori on each platform. Verify your download with `shasum -a 256 -c SHA256SUMS.txt --ignore-missing` (macOS, Linux) or `Get-FileHash <file> -Algorithm SHA256` (PowerShell).

## Known limitations

- Drag and drop works inside Mori only: you can't drag files out to Finder or other apps, or drop files from them into Mori.
- Folders with the same name are never merged: a folder name conflict offers Keep Both or Skip.
- Copying links on Windows needs Developer Mode.
- A move to another drive doesn't carry Mori's private, favorite or tag records to the new drive.
- No build is signed with a publisher certificate or notarized.
- Windows and Linux builds haven't been tested by hand yet, and have weaker decoder isolation than macOS.
- HEIC and PDF previews, new-drive detection and Undo for Trash are macOS features.
- Video and audio are played by the system's media engine, which runs outside Mori's sandbox. No sandbox is an absolute guarantee.
